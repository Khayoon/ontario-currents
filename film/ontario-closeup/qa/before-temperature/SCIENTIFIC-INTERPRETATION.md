# Lake band: source and display interpretation

The broad weak and reversing current band is present in the NOAA surface vector mean. The repeated sharp teeth are a display artifact: each source triangle was painted with one constant vector, and neighboring vectors can point away from their shared edge. Particles then leave an abrupt empty strip following that mesh edge. No missing source values or indexing error were found in the reviewed region.

The corrected display reconstructs a continuous vector field within the same original wet triangles. Shared node values use positive spherical-area weights over edge-connected valid face fans. In each triangle, the original face vector is retained exactly at the barycentric centre, with piecewise linear interpolation toward the shared node values. Missing triangles remain missing, and separate valid fans touching only at a node are kept separate.

For barycentric coordinates `lambda`, let `m = min(lambda)`. The displayed vector is `3m V_face + sum((lambda_i - m) V_corner_i)`. Its weights are nonnegative and sum to one. On a shared edge the centre weight vanishes and both neighboring triangles use the same edge values. The interpolation changes interior display values and does **not** preserve native element means, transport or a discrete FVCOM continuity equation. It is not a new hydrodynamic simulation or an increase in source resolution.

The final helper preserves all 64,453 original face-centre vectors exactly, retains the original valid mask and leaves source objects unchanged. Independent reconstruction agrees within 5.11e-13 m/s. Across 661,528 shared-edge samples, the disagreement is zero. No component overshoot occurs in 128,000 sampled interior points. Strong east/west directions agree over 99.999% of the sampled area, so the broad mean shear remains. The initial spherical determinant had a tiny numerical area-weight discrepancy; a stable equivalent determinant corrected it without relaxing the original comparison threshold. That initial result is retained separately.

Controlled before/after previews use the same original map scale, source data, particle density, seed, warmup, stroke, colors and motion settings. Actual encoded samples show the angular teeth disappear while the broad curved shear and reversing lane remain. A background change alone is not used as motion evidence. Final whole-map video review is recorded separately after encoding.

Primary source metadata identifies `u` and `v` as eastward/northward velocities in m/s at faces. `nv` index order matches the source mesh exactly; the 23-snapshot average reproduces within 5e-7 m/s rounding. The source request and report are in `source-centres-request.json` and `source-neighbour-audit.json`.

A targeted comparison runs the same byte-identical production advection kernel with the two actual raster fields. All 1,156 identical seeds move. In four seconds, 490 original-field traces contain a single substep turn over 20 degrees; none of the reconstructed traces do. The maximum turn changes from 133.9 to 12.2 degrees, while median travel remains comparable (102.1 versus 98.7 output pixels). No invalid-field reset occurs in either set; exits from the diagnostic crop are reported separately. These are descriptive measures of rendered trail kinks, not physical transport or velocity-validation statistics.
