# Upper St. Lawrence input verification

Frozen 19 October 2026 for the 12–17 October Lake Ontario film. These are boundary/validation observations and bathymetry retrieval probes, not current vectors or a completed hydrodynamic simulation.

See [the research and calculation workflow](../../docs/kingston-brockville.md). `SHA256.json` records each retained input/script. The bathymetry probe log contains exact numerical GeoTIFF requests and finite-data counts. Run the scripts from a local clone; output files are written beside each script. The input probes use Python's standard library; bathymetry inspection also needs NumPy and Pillow, and optional thesis extraction needs PyMuPDF. Downloaded PDFs and bathymetry tiles are not included in this folder.

CHS observations, metadata and NONNA bathymetry: Fisheries and Oceans Canada / Canadian Hydrographic Service, [Open Government Licence – Canada](https://open.canada.ca/en/open-government-licence-canada). NOAA intermediate water levels: NOAA CO-OPS. Outflow-change records: International Lake Ontario–St. Lawrence River Board / International Joint Commission. Source URLs and important time, quality, datum and coverage limits are recorded in the linked research note.
